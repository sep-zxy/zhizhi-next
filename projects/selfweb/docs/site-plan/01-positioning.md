# 网站定位

## 一句话定位

一个面向未来自己的公开知识库，同时兼顾 AI/PKM 同好和搜索引擎访客，记录 AI 工具、知识管理、软件使用和个人实践沉淀。

## 主身份

主身份是公开知识库，不是传统个人主页、纯博客，也不是大型软件下载站。

第一版应让读者感知到：

- 这里有结构化的长期知识
- 这里能搜索到具体工具、概念和工作流
- 这里的软件库来自个人使用、测试和收藏，而不是泛泛搬运

## 目标读者

第一优先读者：未来的自己。

因此网站必须满足：

- 内容可追溯
- 页面可搜索
- 结构稳定
- 更新流程可持续
- 不为短期视觉牺牲维护性

兼顾读者：

- AI/PKM 同好：需要看得懂工具实践、知识管理流程和软件使用经验
- 搜索引擎访客：需要清楚标题、摘要、标签和结构化页面

## 第一版主线

第一版主线是：

```text
Obsidian Vault
-> publish: true 公开筛选
-> Quartz 发布
-> Wiki + 软件库
-> 搜索与持续同步
```

## 不做什么

第一版不追求：

- 完整个人品牌站
- 大型软件下载站
- 复杂前端交互
- 一次性迁移全部 Vault 内容
- 自动公开未审核内容
