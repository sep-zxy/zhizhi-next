- 保留 Quartz、既有后端 Markdown 投影、公开资格/Writer 校验，不新建网站正文存储。

## 第三阶段：空库修订日期确定性

复查空库实际 sitemap 时发现上游 CreatedModifiedDate 将 epoch 当作无效日期，回退为构建时钟。保持 vendor 快照不变，在本域 Markdown parse 结束后增加离线日期归一化：只取已审核投影 metadata 的 created/updated/modified，缺失或无效使用固定 epoch，不取文件 mtime 或当前时钟。首页仍显示“暂无修订记录”，不会把 epoch 展示为真实内容更新。
