## C11/C12 运行配置边界

此分支不更改 launcher/打包身份配置。父集成需决定如何在既有本机 viewer 身份已可用时显式注入 ZHIZHI_LEARNING_VIEWER_URL、ZHIZHI_LEARNING_VIEWER_TOKEN；当前 launcher不会自动传递，因此默认未启用。不得向模型暴露这两个配置，不复制 domain agent token，也不发放新身份。

实际路由为 /api/growth/local/knowledge/entry-learning-contexts：
- POST：request_id、entry_id、revision、expected_content_hash。
- GET /{context_id}：回读正式版本和本人已保存原话；校验正文/原话各自 hash。
- POST /{context_id}/note：request_id、expected_context_version、note_text。
- POST /{context_id}/understanding/submissions：context_version、note_sha256；原话只能来自已保存版本。

提交 pending/remote unknown 单独展示，不推定 Writer committed。网络结果不确定不自动重发；让用户回读既有学习页提交记录后决定。运行时可能继续既有模型流程，仍受其已批准权限及额度门禁。
