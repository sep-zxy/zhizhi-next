# 使用入口

知枝包含工程学习界面、私有 Wiki 和只读公开站，Pi 提供工具与本人命令。下载软件或构建源码不包含模型额度、账号授权和个人知识数据。

从 GitHub Actions 的 build.yml 选择目标，下载与 source SHA 对应的产物。正式发行通过 release.yml 发布同一份已保存产物。桌面包仍使用原有用户数据目录，升级前自行备份工作区与 Obsidian Vault。

平台配置参考 config/examples 与 [配置说明](../configuration.md)。默认不启用模型、渠道和自动发布。未经配置的私有入口显示待认证，不提供可直接使用的公共服务。

Obsidian 主编辑与平台的完整双向同步仍待实现；不要把新平台 Git 库当作已经导入全部个人笔记。真实使用旅程与模型/渠道效果需按获准资料单独验收。
