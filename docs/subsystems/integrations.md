# 模型与交互入口

integrations/pi-zhizhi 注册受限工具和本人交互命令；模型可提出变更，不能冒充人工批准或直接写 Git。TypeScript 工具 schema、Python 工具清单和 JSONL 桥需共同校验。

消息连接器目前以材料接收、本人保留决定和回执为主；完整自然语言知识 Agent 交互尚未统一到每个渠道。启动平台不自动配置 Bot、官方微信权限、OpenBao 或模型订阅。

学习前端和私有 Wiki 分别连接明确配置的服务。学习 outbox 保存不可变提交快照，重放保持幂等；原话保存、提交、复核、正式写入分别报告。

公开站只消费通过资格检查的净化投影；Quartz 构建不调用模型，也不代表已经部署或获得真实素材的公开许可。
